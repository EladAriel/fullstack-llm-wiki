# Legacy ``mongo`` Shell

**meta:** :description: Access legacy `mongo` shell documentation, noting its deprecation in favor of `mongosh` in MongoDB v5.0.

.. default-domain:: mongodb

**contents:** On this page
   :local:
   :backlinks: none
   :depth: 1
   :class: singlecol

**warning:** The ``mongo`` shell has been deprecated in MongoDB v5.0. The
   replacement is :binary:`~bin.mongosh`.

   Older ``mongo`` shell documentation is included with the
   corresponding documentation for that ``MongoDB`` release.

   For the legacy ``mongo`` shell documentation, refer to the 
   `legacy documentation <https://www.mongodb.com/docs/legacy/>`__
   for the corresponding MongoDB Server release.
