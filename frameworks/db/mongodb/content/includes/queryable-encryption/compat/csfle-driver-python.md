### Driver Compatibility

To use {+csfle+} with :driver:`PyMongo </python>`, install driver version 3.10.0 or later. To use the Key Rotation API, install [pymongocrypt](https://pypi.org/project/pymongocrypt/)_ version 1.3.1 or later.
