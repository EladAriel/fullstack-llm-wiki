### Driver Compatibility

To use {+csfle+} with the :driver:`Rust </rust>` driver, install driver version 2.4.0 or later. To use the Key Rotation API, install `libmongocrypt <qe-reference-libmongocrypt>` version {+minimum-libmongocrypt-version+} or later.
