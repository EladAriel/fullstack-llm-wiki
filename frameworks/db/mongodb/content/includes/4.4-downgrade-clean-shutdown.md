Run the following command in :binary:`~bin.mongosh` to perform a clean shutdown, or refer to `terminate-mongod-processes` for additional ways to safely terminate the :binary:`~bin.mongod` process:

```javascript
db.adminCommand( { shutdown: 1 } )
```
