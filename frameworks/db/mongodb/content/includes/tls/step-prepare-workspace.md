Create and navigate to a directory to store your key and certificate files.

On Linux or MacOS, run the following commands:

```bash
mkdir -p ~/mongo-tls
cd ~/mongo-tls
```

In Windows Command Prompt or PowerShell:

```shell
mkdir C:\mongo-tls
cd C:\mongo-tls
```
